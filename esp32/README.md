# 📡 คู่มือการเชื่อมต่อฮาร์ดแวร์ ESP32 กับ IoT WebApp

ระบบนี้เตรียมฐานข้อมูลและ REST API สำหรับรับส่งข้อมูลกับบอร์ด **ESP32** จริงไว้เรียบร้อยแล้ว โดยไม่ใช้ค่าสุ่มจำลอง (Fake Data) หากยังไม่มีบอร์ดส่งข้อมูลเข้ามา ระบบจะแสดงสถานะเป็น **"ออฟไลน์" (Offline)** ทันที

---

## 🚀 สถาปัตยกรรมการเชื่อมต่อ (How it Works)

1. **ESP32 ส่งข้อมูลเซนเซอร์:**
   - ESP32 อ่านค่าเซนเซอร์ (อุณหภูมิ, ความชื้น, แสง, CO₂)
   - ส่ง HTTP POST มาที่: `http://<IP-เครื่องหรือโดเมน>:3000/api/esp32/telemetry`
   - โครงสร้าง JSON:
     ```json
     {
       "deviceId": "esp32-zone1",
       "temp": 26.5,
       "humid": 85.0,
       "lux": 350,
       "co2": 680
     }
     ```
2. **เซิร์ฟเวอร์จัดเก็บลงฐานข้อมูล (`data/db.json`):**
   - บันทึกค่าเซนเซอร์ล่าสุด + เวลาที่ส่ง (`lastSeen`)
   - บันทึกประวัติข้อมูล (History Log)
3. **ส่งสถานะ Relay กลับให้ ESP32 สั่งงานจริง:**
   - เซิร์ฟเวอร์จะตอบกลับคำสั่งสวิตช์เปิด-ปิดปัจจุบันของ WebApp ทันที:
     ```json
     {
       "success": true,
       "connected": true,
       "relays": {
         "fogger": true,
         "fan": false,
         "light": true,
         "curtain": false
       }
     }
     ```
   - ESP32 สั่งขา Relay (GPIO 25, 26, 27, 14) ให้เปิดหรือปิดตามที่ผู้ใช้กดจากหน้าจอ WebApp

---

## ⚡ วิธีทดสอบจำลองส่งข้อมูลจาก ESP32 ผ่านคำสั่ง cURL / PowerShell

หากต้องการทดสอบส่งข้อมูลเข้าฐานข้อมูลจริงทันทีเพื่อดูหน้าเว็บเปลี่ยนเป็น **"ออนไลน์"** สามารถรันคำสั่งนี้ได้ใน Terminal:

```bash
# ส่งค่าเซนเซอร์ทดสอบ
curl -X POST http://localhost:3000/api/esp32/telemetry \
  -H "Content-Type: application/json" \
  -d '{"temp": 27.2, "humid": 82.5, "lux": 450, "co2": 620}'
```

เมื่อส่งแล้ว:
- หน้าแรกจะเปลี่ยนเป็น **"ออนไลน์"** ทันที พร้อมแสดงตัวเลขเซนเซอร์จริง
- หน้าสถานะอุปกรณ์จะขึ้น **"ออนไลน์"** ทั้ง 5 อุปกรณ์
- หากไม่มีการส่งข้อมูลติดต่อกันเกิน 25 วินาที ระบบจะตัดกลับเป็น **"ออฟไลน์"** อัตโนมัติ
