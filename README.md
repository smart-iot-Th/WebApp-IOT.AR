# IoT WebApp (Smart Connected Devices Dashboard)

เว็บแอปพลิเคชันระบบควบคุมและติดตามอุปกรณ์อัจฉริยะ **IoT WebApp** แบบ **Progressive Web App (PWA)** ดีไซน์ธีม Sky Blue & Royal Blue สุดพรีเมียม รองรับการเปิดใช้งานแบบ **เต็มจอ 100% (Standalone Mode) ไร้แถบ URL หรือกรอบเบราว์เซอร์ด้านบน** เมื่อเพิ่มลงในหน้าจอโฮมของโทรศัพท์มือถือ พร้อมบล็อกฟังก์ชันพร้อมเชื่อมต่ออุปกรณ์จริงในอนาคต

---

## 🌟 โครงสร้างหน้าจอและฟังก์ชันการทำงาน

1. **หน้าเข้าสู่ระบบ (Login Screen):**
   - ภาพประกอบสมาร์ตโฮมและเครือข่ายอุปกรณ์ IoT เชื่อมต่อไร้สาย
   - ฟอร์มเข้าสู่ระบบ (อีเมล/ชื่อผู้ใช้, รหัสผ่าน พร้อมปุ่มเปิด-ปิดตาดูรหัส)
   - ตัวเลือก "จำฉันไว้" และลิงก์ลืมรหัสผ่าน
   - ปุ่มเข้าสู่ระบบแบบ Guest Instant Login และปุ่ม "เข้าสู่ระบบด้วย Google"
2. **หน้าแรก (Home Dashboard):**
   - แบนเนอร์ภาพรวมเครือข่ายอุปกรณ์ IoT พร้อมสถานะ "เชื่อมต่อระบบปกติ"
   - บล็อกแสดงค่าสภาพแวดล้อม 4 เซนเซอร์แบบ 2x2 Grid (อุณหภูมิ, ความชื้น, CO₂, แสงสว่าง)
3. **ควบคุม (Control System):**
   - สลับโหมดการทำงาน: อัตโนมัติ / กำหนดเอง
   - แผงสวิตช์เปิด-ปิดอุปกรณ์ (หัวพ่นหมอก, พัดลมระบายอากาศ, ไฟส่องสว่าง, ม่านระบาย)
   - ลิงก์ฟังก์ชันตั้งเวลา (Timer Schedule) และปุ่มบันทึกการตั้งค่า
4. **กราฟ (Sensor Graphs & Data):**
   - ตัวกรองช่วงเวลา: 24 ชม. / 7 วัน / 30 วัน
   - กราฟเส้น Area Chart แสดงแนวโน้มอุณหภูมิ, ความชื้น และแสงสว่าง
5. **แจ้งเตือน (Notifications & Alerts):**
   - รายการแจ้งเตือนตามเหตุการณ์จริง
6. **ตั้งค่า (Settings & Modular Blocks):**
   - **หน้าตั้งค่าหลัก:** บล็อกกำหนดค่ามาตรฐาน (อุณหภูมิ, ความชื้น, แสง, CO₂) ปรับแต่งได้ทันทีผ่าน Modal Popup
   - **สถานะอุปกรณ์ (Device Status):** ตรวจสอบสถานะการเชื่อมต่ออุปกรณ์ 5 ตัว (เซนเซอร์, หัวพ่นหมอก, พัดลม, ไฟ LED, ตู้ควบคุม IoT) พร้อมไฟสถานะออนไลน์
   - **ตั้งเวลาอัตโนมัติ (Automation / Schedule):** กรองหมวดหมู่ (พ่นหมอก, พัดลม, ไฟส่องสว่าง), สวิตช์เปิด-ปิด และปุ่มเพิ่มตารางเวลาใหม่
   - **ข้อมูลผู้ใช้งาน (User Profile):** ข้อมูลโปรไฟล์ผู้ดูแลระบบ IoT, แก้ไขข้อมูล, เปลี่ยนรหัสผ่าน, เลือกภาษา และปุ่มออกจากระบบ (Logout) กลับสู่หน้า Login

## 📲 วิธีติดตั้งเป็นแอปในมือถือ (ไร้ URL Bar 100%)

### สำหรับ iPhone / iPad (Safari)
1. เปิดลิงก์เว็บนี้ด้วย **Safari**
2. กดปุ่ม **แชร์ (Share)** *(ไอคอนสี่เหลี่ยมที่มีลูกศรชี้ขึ้นที่แถบล่าง)*
3. เลื่อนลงแล้วกด **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
4. กด **"เพิ่ม" (Add)** ที่มุมขวาบน

### สำหรับ Android (Chrome)
1. เปิดลิงก์เว็บนี้ด้วย **Google Chrome**
2. แตะปุ่ม **"เพิ่มเป็นไอคอนแอปบนหน้าจอมือถือ"** ในแท็บตั้งค่า หรือกดเมนู 3 จุด (**⋮**)
3. เลือก **"ติดตั้งแอปพลิเคชัน" (Install app)** หรือ **"เพิ่มลงในหน้าจอหลัก"**

### ⚙️ ขั้นตอนการเปิดใช้งาน GitHub Pages ใน Repository (ทำเพียงครั้งเดียว)
1. ไปที่ GitHub Repository: [https://github.com/smart-iot-Th/WebApp-IOT.AR](https://github.com/smart-iot-Th/WebApp-IOT.AR)
2. คลิกแท็บ **Settings** ด้านบน
3. แถบเมนูด้านซ้าย เลือก **Pages** (ภายใต้หัวข้อ Code and automation)
4. ในส่วน **Build and deployment**:
   - **Source:** เลือก `Deploy from a branch`
   - **Branch:** เลือก `main` และโฟลเดอร์เลือก `/ (root)`
5. กดปุ่ม **Save** ระบบจะ Build และเปิดให้ใช้งานที่ `https://smart-iot-th.github.io/WebApp-IOT.AR/` โดยอัตโนมัติ ทุกครั้งที่มีการ `git push` โค้ดใหม่ขึ้น branch `main`
