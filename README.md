# NovaHub - Standalone Mobile Web App (PWA)

เว็บแอปพลิเคชันส่วนตัวแบบ **Progressive Web App (PWA)** รองรับการเปิดใช้งานแบบ **เต็มจอ 100% (Standalone Mode) ไร้แถบ URL หรือกรอบเบราว์เซอร์ด้านบน** เมื่อเพิ่มลงในหน้าจอโฮมของโทรศัพท์มือถือ สามารถเข้าใช้งานได้จากทุกที่ที่มีอินเทอร์เน็ต

---

## 🌟 คุณสมบัติเด่น (Features)

1. **โหมดแอปเต็มจอ (Standalone Native Feel):**
   - ไม่มีแถบที่อยู่เว็บ (URL / Address Bar) หรือปุ่มควบคุมของเบราว์เซอร์มากวนใจ
   - รองรับ Safe Area Insets สำหรับติ่งหน้าจอ iPhone (Dynamic Island / Notch) และแถบโฮมด้านล่าง
   - ดีไซน์สวยงามระดับพรีเมียม สไตล์ Dark Modern Glassmorphism & Neon Gradients
2. **ศูนย์รวมทางลัดและแอป (App Hub & Shortcuts):**
   - รวมลิงก์เว็บไซต์และแอปที่คุณใช้งานเป็นประจำ
   - เพิ่ม ลบ และปรับแต่งทางลัดได้อิสระ พร้อมเลือกไอคอนและสีสัน
3. **สมุดจดโน้ต & สิ่งที่ต้องทำ (Tasks & Notes):**
   - จัดการ To-Do List ในแต่ละวัน ติ๊กถูกเมื่องานเสร็จ
   - สมุดบันทึกข้อความด่วนสำหรับเก็บข้อมูลสำคัญ
4. **บันทึกรายรับ-รายจ่าย (Finance Tracker):**
   - ติดตามยอดเงินคงเหลือ บันทึกเงินเข้าและค่าใช้จ่ายประจำวัน
5. **ระบบออฟไลน์และแคชความเร็วสูง (Service Worker):**
   - โหลดหน้าเว็บได้ทันทีแม้สัญญาณอินเทอร์เน็ตช้าหรือขาดหาย
   - มีระบบสำรองข้อมูล (Backup & Restore) บันทึกและกู้คืนไฟล์ JSON ได้ทุกเมื่อ

## 📲 วิธีติดตั้งเป็นแอปในโทรศัพท์มือถือ (ไร้ URL Bar 100%)

### สำหรับ iPhone / iPad (ผ่าน Safari)
1. เปิดลิงก์เว็บแอปนี้ด้วยเบราว์เซอร์ **Safari**
2. แตะปุ่ม **แชร์ (Share)** (ไอคอนสี่เหลี่ยมที่มีลูกศรชี้ขึ้นที่แถบล่าง)
3. เลื่อนลงมาแล้วเลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
4. แตะปุ่ม **"เพิ่ม" (Add)** ที่มุมขวาบน
5. *ผลลัพธ์:* จะมีไอคอนแอป **NovaHub** บนหน้าจอโฮม เมื่อกดเปิด จะเปิดเป็นหน้าแอปเต็มจอโดยไม่มีแถบ URL ด้านบนทันที!

### สำหรับ Android (ผ่าน Chrome หรือ Samsung Internet)
1. เปิดลิงก์เว็บแอปนี้ด้วย **Google Chrome**
2. แตะปุ่ม **"ติดตั้งแอป"** ที่แถบด้านบนของหน้าเว็บ หรือแตะเมนู 3 จุด (**⋮**) ที่มุมบนขวา
3. เลือก **"ติดตั้งแอปพลิเคชัน" (Install app)** หรือ **"เพิ่มลงในหน้าจอหลัก" (Add to Home screen)**
4. *ผลลัพธ์:* ระบบจะสร้างแอปขึ้นมา เปิดใช้งานได้เต็มจอเหมือนแอปจาก Play Store

## 🌐 วิธีนำขึ้นอินเทอร์เน็ต เพื่อให้เปิดได้จากโทรศัพท์ทุกที่ทั่วโลก (ฟรี 100%)

เนื่องจาก PWA จำเป็นต้องมี HTTPS คุณสามารถนำโฟลเดอร์นี้ไปอัปโหลดขึ้นโฮสติ้งฟรีได้ง่ายๆ ภายใน 1-2 นาที:

### วิธีที่ 1: Netlify Drop (ง่ายที่สุด ไม่ต้องพิมพ์คำสั่ง)
1. เข้าเว็บไซต์ [app.netlify.com/drop](https://app.netlify.com/drop)
2. ลากโฟลเดอร์ `d:\Web App` ไปวางลงในกรอบสี่เหลี่ยมบนหน้าเว็บ
3. รอระบบประมวลผลประมาณ 15 วินาที คุณจะได้ลิงก์เว็บไซต์แบบ HTTPS (เช่น `https://xxxx.netlify.app`) นำไปเปิดในมือถือได้ทันที

### วิธีที่ 2: Vercel (เร็วและเสถียรมาก)
1. เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์:
   ```bash
   npx vercel
   ```
2. ทำตามขั้นตอนบนหน้าจอ (เข้าสู่ระบบด้วย Google หรือ GitHub) เพียง 1 นาทีก็ได้ลิงก์ใช้งานทันที

### วิธีที่ 3: GitHub Pages
1. นำโค้ดขึ้น GitHub Repository
2. เข้าไปที่ **Settings > Pages** และเลือก Branch `main` เพื่อเปิดใช้งานฟรีตลอดชีพ

```bash
npm start
```
