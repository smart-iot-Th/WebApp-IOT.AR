# โรงเห็ดของฉัน (Smart Mushroom Farm IoT Dashboard)

เว็บแอปพลิเคชันควบคุมและติดตามสภาพแวดล้อมโรงเห็ดอัจฉริยะแบบ **Progressive Web App (PWA)** รองรับการเปิดใช้งานแบบ **เต็มจอ 100% (Standalone Mode) ไร้แถบ URL หรือกรอบเบราว์เซอร์ด้านบน** เมื่อเพิ่มลงในหน้าจอโฮมของโทรศัพท์มือถือ

---

## 🌟 โครงสร้างหน้าจอทั้ง 5 แท็บตามภาพอ้างอิง

1. **หน้าแรก (Home Dashboard):**
   - รูปภาพโรงเห็ดพร้อมป้ายสถานะ "ระบบทำงานปกติ"
   - บล็อกแสดงค่าสภาพแวดล้อม 4 เซนเซอร์แบบ 2x2 Grid:
     - 🌡️ **อุณหภูมิ:** `26.5 °C` (ช่วงปลอดภัย: 24 - 28 °C)
     - 💧 **ความชื้น:** `85 %` (ช่วงปลอดภัย: 80 - 90 %)
     - ☁️ **CO₂:** `680 ppm` (ช่วงปลอดภัย: < 1,000 ppm)
     - ☀️ **แสงสว่าง:** `350 lux` (ช่วงปลอดภัย: 200 - 1,000 lux)
2. **ควบคุม (Control System):**
   - สลับโหมดการทำงาน: **อัตโนมัติ** / **กำหนดเอง**
   - แผงสวิตช์เปิด-ปิดอุปกรณ์ (Toggle Switches):
     - ระบบพ่นหมอก (เปิด/ปิด)
     - พัดลมระบายอากาศ (เปิด/ปิด)
     - ไฟส่องสว่าง (เปิด/ปิด)
     - ม่านพัดลมระบาย (เปิด/ปิด)
   - ลิงก์ฟังก์ชัน **ตั้งเวลา (Timer Schedule)**
   - ปุ่มกด **"บันทึกการตั้งค่า"**
3. **กราฟ (Sensor Graphs & Data):**
   - ตัวกรองช่วงเวลา: **24 ชม.** / **7 วัน** / **30 วัน**
   - กราฟเส้นแบบ Area Chart 3 กราฟ พร้อมป้ายค่าปัจจุบัน:
     - อุณหภูมิ (°C)
     - ความชื้น (%)
     - แสงสว่าง (lux)
4. **แจ้งเตือน (Notifications & Alerts):**
   - ฟิลเตอร์หมวดหมู่: **ทั้งหมด** / **คำเตือน** / **ระบบ** / **ข้อความ**
   - รายการแจ้งเตือนตามเหตุการณ์จริง (อุณหภูมิเกิน, ความชื้นต่ำ, การทำงานของพ่นหมอก/พัดลม)
5. **ตั้งค่า (Settings & Theme):**
   - **สลับธีม ขาว-ดำ (Light / Dark Theme):**
     - ☀️ **ธีมสีขาว (Clean Mode):** โทนสีขาวเขียว คลีนตาตามภาพอ้างอิง
     - 🌙 **ธีมสีดำ (Dark Mode):** โทนสีมืด สบายตาในเวลากลางคืน
   - สวิตช์จำลองค่าเซนเซอร์แบบ Real-time (ตัวเลขขยับสมจริงเหมือนต่อบอร์ด IoT)
   - ปุ่มติดตั้งเป็นแอปในมือถือ (PWA Install)

---

## 📲 วิธีติดตั้งเป็นแอปในมือถือ (ไร้ URL Bar 100%)

### สำหรับ iPhone / iPad (Safari)
1. เปิดลิงก์เว็บนี้ด้วย **Safari**
2. กดปุ่ม **แชร์ (Share)** *(ไอคอนสี่เหลี่ยมที่มีลูกศรชี้ขึ้นที่แถบล่าง)*
3. เลื่อนลงแล้วกด **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
4. กด **"เพิ่ม" (Add)** ที่มุมขวาบน

### สำหรับ Android (Chrome)
1. เปิดลิงก์เว็บนี้ด้วย **Google Chrome**
2. แตะปุ่ม **"เพิ่มเป็นไอคอนแอปบนหน้าจอมือถือ"** ในแท็บตั้งค่า หรือกดเมนู 3 จุด (**⋮**)
3. เลือก **"ติดตั้งแอปพลิเคชัน" (Install app)** หรือ **"เพิ่มลงในหน้าจอหลัก"**

## 🌐 วิธีนำขึ้น Netlify ใหม่อีกครั้ง
1. เข้าไปที่หน้าเว็บเดิมใน Netlify ที่ [app.netlify.com](https://app.netlify.com)
2. ไปที่แท็บ **Deploys**
3. ลากโฟลเดอร์ `d:\Web App` วางในช่องอัปเดตเพื่อนำไฟล์เวอร์ชันใหม่ไปใช้งานได้ทันที
