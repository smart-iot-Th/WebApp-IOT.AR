วิธีเปิดแจ้งเตือนบน iPhone (iOS)

📱
ตามระบบความปลอดภัยของ Apple (iOS 16.4+) จำเป็นต้อง "เพิ่มไปยังหน้าจอโฮม" ก่อน จึงจะเปิดรับการแจ้งเตือนได้ครับ
1
กดปุ่ม แชร์ (Share) ที่แถบด้านล่างของ Safari
2
เลื่อนลงแล้วเลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen) แล้วกด "เพิ่ม"
3
เปิด IoT WebApp จากไอคอนบนหน้าจอโฮม แล้วกด "เปิดแจ้งเตือน" ได้ทันที!

คู่มือเชื่อมต่อบอร์ด ESP32 จริง

ระบบเตรียม REST API และฐานข้อมูลไว้พร้อมรับข้อมูลจากบอร์ด ESP32 โดยตรง ไม่ใช้ค่าจำลอง (ถ้ายังไม่มีบอร์ดส่งข้อมูล ระบบจะขึ้นสถานะ ออฟไลน์)

📡 HTTP POST Endpoint:
POST /api/esp32/telemetry
📦 โครงสร้าง JSON ที่ ESP32 ส่งเข้ามา:
{
  "deviceId": "esp32-zone1",
  "temp": 26.5,
  "humid": 84.0,
  "lux": 450,
  "co2": 620
}
📥 สิ่งที่ ESP32 จะได้รับตอบกลับ (คำสั่ง Relay):
{
  "success": true,
  "connected": true,
  "relays": {
    "fogger": true,
    "fan": false,
    "light": false,
    "curtain": false
  }
}
📁 ไฟล์โค้ด Arduino สมบูรณ์:
เปิดดูหรือคัดลอกโค้ดไปแฟลชลง ESP32 ได้ที่ไฟล์:
esp32/esp32_iot_webapp.ino

☁️ วิธีเปิดใช้งานออนไลน์ 24 ชม. ผ่าน Firebase

ทำตามขั้นตอนง่าย ๆ เพื่อให้ ESP32 และเว็บแอปบน GitHub Pages สามารถเชื่อมต่อกันได้จากทุกที่ทั่วโลก ฟรีตลอดชีพ โดยไม่ต้องเปิดคอมพิวเตอร์:

ขั้นตอนที่ 1: สร้าง Firebase Project ฟรี
1. ไปที่เว็บไซต์ console.firebase.google.com แล้วล็อกอินด้วย Gmail
2. กดปุ่ม "เพิ่มโปรเจกต์" (Add project) ตั้งชื่อ เช่น iot-webapp แล้วกดสร้างเสร็จสิ้น
ขั้นตอนที่ 2: สร้าง Realtime Database
1. ในเมนูด้านซ้าย เลือก Build > Realtime Database
2. กด "สร้างฐานข้อมูล" (Create Database)
3. เลือกตำแหน่งเซิร์ฟเวอร์ เช่น Singapore แล้วกดถัดไป
4. เลือกความปลอดภัยเป็น "เริ่มต้นในโหมดทดสอบ" (Start in test mode) แล้วกดเปิดใช้งาน
ขั้นตอนที่ 3: คัดลอก Database URL มาใส่ในแอปนี้
คัดลอก URL ที่ปรากฏด้านบน (เช่น https://your-app-default-rtdb.asia-southeast1.firebasedatabase.app) แล้วนำมาวางในช่อง Firebase Realtime Database URL ในหน้านี้แล้วกดบันทึก
ขั้นตอนที่ 4: ใส่ URL ลงในโค้ด Arduino ESP32
เปิดไฟล์ esp32/esp32_iot_webapp/esp32_iot_webapp.ino
ตั้งค่า #define USE_FIREBASE_CLOUD 1 และวาง URL เดียวกันนี้ลงในตัวแปร FIREBASE_HOST แล้วกด Upload ลงบอร์ด ESP32!
