วิธีเพิ่มเป็นแอปบนมือถือ (ไร้ URL Bar)
1
เปิดเว็บนี้ใน Safari
เปิดลิงก์เว็บแอปนี้ด้วยเบราว์เซอร์ **Safari** บน iPhone หรือ iPad ของคุณ
2
กดปุ่มแชร์ (Share)
แตะที่ไอคอนรูปกล่องสี่เหลี่ยมที่มีลูกศรชี้ขึ้น (Share / แบ่งปัน) ตรงแถบเมนูด้านล่างของ Safari
3
เลือก "เพิ่มไปยังหน้าจอโฮม"
เลื่อนเมนูลงมาแล้วแตะที่ "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
4
กด "เพิ่ม" (Add)
กดปุ่ม "เพิ่ม" ที่มุมขวาบน จะมีไอคอนแอป NovaHub ไปอยู่ที่หน้าจอมือถือของคุณทันที เมื่อกดเปิดจะเป็นหน้าแอปเต็มจอ 100% ไร้แถบ URL!
1
เปิดเว็บนี้ใน Chrome
เปิดลิงก์เว็บแอปนี้ด้วย Google Chrome หรือ Samsung Internet
2
กดเมนู 3 จุด ( ⋮ ) หรือปุ่มติดตั้ง
แตะที่เมนู 3 จุดมุมบนขวา หรือแตะปุ่ม "ติดตั้งแอป" ที่แถบด้านบนของหน้านี้
3
เลือก "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"
เลือก **"ติดตั้งแอปพลิเคชัน" (Install app)** หรือ **"เพิ่มลงในหน้าจอหลัก" (Add to Home screen)**
4
เปิดใช้งานได้ทันที
ระบบจะสร้างแอปในหน้ารวมแอปและหน้าจอหลัก เปิดแบบ Standalone เต็มจอไร้กรอบเบราว์เซอร์

🌐 วิธีเปิดใช้งานจากทุกที่ที่มีอินเทอร์เน็ต (ฟรี 100%)

เพื่อให้คุณสามารถเข้าเว็บนี้ได้จากโทรศัพท์ทุกเครื่อง ทุกที่ทั่วโลก เพียงนำโฟลเดอร์นี้ไปอัปโหลดขึ้นโฮสติ้งฟรี เช่น:

• Vercel / Netlify: ลากโฟลเดอร์นี้วางที่หน้า Dashboard หรือเชื่อมผ่าน GitHub ใช้เวลาเพียง 1 นาที ได้ลิงก์ HTTPS ส่วนตัวทันที
• Cloudflare Pages: ปล่อยเว็บฟรี พร้อมเครือข่ายเร็วที่สุดในโลก
• GitHub Pages: สร้าง Repository แล้วเปิด GitHub Pages ฟรีตลอดชีพ
